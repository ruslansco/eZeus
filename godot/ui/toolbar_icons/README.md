# Illustrated city toolbar icons

Original vector artwork authored for the Godot city toolbar on 5 October 2026.
The supplied Anno 1800 screenshot informed the compact illustrated presentation;
none of its pixels, illustrations, symbols or game assets were copied or embedded.
These sources are covered by the repository license.

The 96×96 transparent SVGs use shaded limestone, terracotta, wood and bronze with
green and blue accents. Each category has a distinct silhouette. Display at
34–36 logical pixels (32 minimum); the art includes its own colours, so apply a
neutral white icon tint. Hover, keyboard focus and active frames belong to the
shared Theme, outside these drawings. No live model viewport or Blender process
is needed by the toolbar.

Categories: `homes`, `agriculture`, `industry`, `storage`, `trade`, `markets`,
`water`, `civic`, `defence`, `culture`, `science`, `sanctuaries`, `pyramids`,
`shrines`, `heroes`, `gardens`, and `build`. `food.svg` is the same wheat artwork
as `agriculture.svg`, retained for the existing category-art key.

Utilities: `inspect` (magnifier), `road` (limestone paving), `demolish` (pickaxe),
`undo` (return arrow), `layers` (stacked ground), and `map` (folded coastal chart).

Header illustrations: `treasury` (stacked silver coins with an owl relief) and
`population` (two citizens in linen and colored cloaks). Both use the same
24×24 logical-pixel, aspect-preserving cells, alongside the native values.
The static treasury image replaces the live coin viewport and its flip effect;
native money, ledger colors, counts, mood and hover help remain unchanged.

The category names, hover copy, availability and callbacks stay in the HUD and
native catalogue; these drawings add no simulation or save semantics.

`roadblock.svg` (6 October 2026) is an original colored timber barrier over a
paved road, drawn for the direct roadblock shortcut. It uses no reference-image
pixels or live rendering.
