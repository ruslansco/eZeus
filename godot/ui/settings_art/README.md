# Original Greek settings vectors

These SVGs were authored directly for the game's start-menu settings shell
on 10 October 2026. They are original source artwork, with no screenshot crops,
external icon set or generated bitmap. Bronze meander trim, dark blue enamel,
ivory marks and restrained bevels match the established Greek menu palette.

`bronze_frame.svg` is nine-sliced with a reserved title band. The other vectors
provide the close control, dropdown arrow, slider handle and checkbox states.
`ui/settings_shell.gd` uses the original walnut/gold/ivory bitmap frame for all six
Settings forms in the main menu and city. `bronze_frame.svg` remains for quiet
native menu confirmations. These other vectors provide readable form details in
private dialog Themes; native settings behavior remains code-native.

`menu_action.svg` adds an original blue-enamel/bronze beveled action surface for
explicit menu footer, profile Create/Delete and catalog pager variations. Its
plain interior reserves label padding; state tints distinguish primary, secondary,
destructive, hover, press, disabled and focus. It does not skin generic settings
buttons or key caps. No bitmap generation or external artwork was used.
